# AI-HOS v2.0 — AI Hospital Operating System

HIPAA-aware **Clinical Documentation AI** + **Automated Prior Authorization Engine** + **React Clinician Dashboard**.

- **Full overview & setup guide**: [WHAT_IS_THIS_AND_HOW_TO_RUN.md](./WHAT_IS_THIS_AND_HOW_TO_RUN.md)
- **One-paste Windows launcher**: Run `.\run.bat` (or `D:\Projects\AI-HOS\run.bat`) in Command Prompt or PowerShell.
- **Stop all services**: Run `.\stop.bat`.

| Service | URL |
|---|---|
| Clinician Dashboard (React + Vite) | http://localhost:5173 |
| Clinical Documentation AI (Swagger Docs) | http://localhost:8000/docs |
| Prior Authorization Engine (Swagger Docs) | http://localhost:8001/docs |
